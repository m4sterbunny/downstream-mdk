# Release v0.2.0

Released: June 2026

**Current release:** v0.2.0

## Overview

MDK v0.2.0 is the first SemVer-aligned monorepo release after the architectural restructure. It delivers a federated three-domain layout (`backend/core`, `backend/workers`, `ui`), a formal worker protocol contract, Zustand-based UI state, React 19, and an agent-first CLI with MCP support on the app-node.

This release supersedes the pre-release `0.0.x` versioning used during early development. See [v0.0.1 release notes](./0.0.1-release.md) for the inaugural UI-focused release history.

## Package versions

The monorepo root (`@tetherto/mdk`) tracks the **MDK release line** at **0.2.0**. Individual publishable packages use their own semver within that release:

| Package | Version | Notes |
|---|---|---|
| `@tetherto/mdk` (root) | **0.2.0** | Umbrella orchestrator; defines the release line |
| `mdk-ui` (UI workspace) | 0.0.2 | UI workspace root; tracks UI workspace iteration |
| `@tetherto/mdk-ui-core` | 0.0.1 | Headless state layer |
| `@tetherto/mdk-react-adapter` | 0.0.1 | React bindings |
| `@tetherto/mdk-react-devkit` | 0.0.1 | Component library |
| `@tetherto/mdk-ui-cli` | 0.0.1 | `mdk-ui` CLI binary |
| `@tetherto/mdk-fonts` | 0.0.1 | Font assets |
| `@tetherto/mdk-core` | 0.0.1 | Backend core umbrella |
| `@tetherto/mdk-core-workers` | 0.0.1 | Backend workers umbrella |

`backend/core` and `backend/workers` remain at **0.0.1** under an **independent per-domain versioning model**. They are consumed from the monorepo workspace and are not bumped in lockstep with the root release line until published independently.

## Requirements

- **Node.js** >= 24 (LTS recommended)
- **npm** >= 11 (UI workspace)

## Highlights

### Backend

- **ORK rewrite** — DHT discovery, HRPC transport, IPC gateway, telemetry collector, command dispatcher, health monitor
- **New MDK API** — `getOrk`, `startWorker`, `startAppNode`, `waitForDiscovery`, `startServices`
- **Worker contracts** — every worker ships `mdk-contract.json` with telemetry, commands, health, and error catalogues
- **Worker catalogue** — miners (antminer, avalon, whatsminer), containers (antspace, bitdeer, microbt), minerpools (ocean, f2pool), power-meter (abb, satec, schneider, electricity), temperature (seneca)
- **App-node MCP endpoint** — AI agents can query fleet state and issue commands
- **Services module** — PM2 and Docker orchestration via `startServices(config)`

### UI

- **Package split** — `@tetherto/mdk-ui-core`, `@tetherto/mdk-react-adapter`, `@tetherto/mdk-react-devkit`, `@tetherto/mdk-ui-cli`
- **Zustand stores** replace Redux Toolkit slices
- **React 19** across all UI packages
- **Agent-first CLI** — `mdk-ui create`, `add page`, `suggest`, registry discovery, and IDE seeding via `mdk-ui init`
- **Catalog app** — `@tetherto/mdk-catalog-ui` replaces the legacy demo app

### Documentation

- Root `docs/` with concepts, tutorials, how-to guides, and maintainer reference
- Worker docs under `backend/workers/docs/`
- Agent entry points: `ui/AGENTS.md`, `ui/docs/AGENT_FIRST.md`

## Breaking changes

See [CHANGELOG.md](../../../CHANGELOG.md) for the full breaking-change list. Key migrations:

1. **Directory layout** — `core/` → `backend/core/`, `ui-client/` → `ui/`, workers promoted to `backend/workers/`
2. **Node.js** — minimum raised from 20 to **24**
3. **Package manager** — pnpm removed; use npm in the UI workspace
4. **State layer** — Redux Toolkit → Zustand (`@tetherto/mdk-ui-core`)
5. **Core API** — `initType` / `startApi` → `getOrk` / `startWorker` / `startAppNode`

## Upgrade from v0.0.1

If you adopted the inaugural v0.0.1 UI packages:

1. Update imports from legacy `@tetherto/mdk-core-ui` / `@tetherto/mdk-foundation-ui` to the new split packages
2. Replace Redux store usage with `@tetherto/mdk-ui-core` Zustand stores and `@tetherto/mdk-react-adapter` hooks
3. Wrap your app in `<MdkProvider>` from `@tetherto/mdk-react-adapter`
4. Switch from pnpm to npm for the UI workspace
5. Upgrade Node.js to 24+

For backend integrations on the pre-0.2.0 layout, follow the path mapping table in [CHANGELOG.md](../../../CHANGELOG.md).

## Install

From a published release checkout or tag:

```bash
git clone https://github.com/tetherto/mdk.git
cd mdk
git checkout v0.2.0
npm run setup
```

Scaffold a dashboard app with the CLI:

```bash
npx @tetherto/mdk-ui-cli create my-app
cd my-app
npm run dev
```

When working inside the monorepo before packages are published, build the CLI first (`npm run build --workspace @tetherto/mdk-ui-cli`) and invoke via `npx mdk-ui` from the UI workspace.
